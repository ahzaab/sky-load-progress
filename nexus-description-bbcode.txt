[center][font=Arial][color=#f1c232][size=5][i][b]Clean Loading Transitions[/b][/i][/size][/color][/font][/center]


[i][color=gray][size=4][b]Description[/b][/size][/color][/i]

Skyrim is still loading the same cells. This mod changes what you see while it happens.

Clean Loading Transitions replaces Skyrim's black loading fades with an image of the last completed frame. If the destination cell is already in memory, the mod transitions directly into it. If the cell still needs to be loaded, the normal Loading Menu remains visible over a blurred or colored version of the captured frame.

The mod does not make Skyrim load cells faster. It can still feel faster because player controls resume without waiting for the normal Fader Menu animation to finish.

No ESP, Papyrus scripts, or save-game data are used.

[color=gray][size=4][i][b]Features[/b][/i][/size][/color]

[list=1]
[*]Captures the last world frame before Skyrim stops rendering.[/*]
[*]Keeps the HUD, console, and other ScaleForm menus out of the captured image.[/*]
[*]Removes the normal black fade, mist, background, and loading-screen models.[/*]
[*]Blurs the captured frame while the next cell loads.[/*]
[*]Blends the captured frame into the newly loaded cell.[/*]
[*]Returns player control without waiting for the normal Fader Menu animation to finish.[/*]
[*]Uses different transitions depending on whether the cell is already in memory.[/*]
[*]Supports blur, fixed-color, and dominant-color transitions.[/*]
[*]Supports custom transitions based on Cell Editor ID patterns.[/*]
[*]Adds a configurable loading progress meter.[/*]
[*]Keeps the vanilla level bar and loading tips during longer loads.[/*]
[/list]

[color=gray][size=4][i][b]How Transitions Are Selected[/b][/i][/size][/color]

The mod checks whether the destination cell is already in memory before choosing a transition.

[b]Cell already in memory[/b]

When the cell is already in memory, the Loading Menu is hidden. The last completed frame stays visible and then blends directly into the new cell.

There is no initial transition delay.

[b]Cell not in memory[/b]

When the cell is not in memory, the Loading Menu remains visible. Its level bar, loading tips, and progress meter can still be displayed.

The captured frame replaces the normal black background. By default, it is blurred while the cell loads and then blends into the new scene.

These loads can also use a color transition. The color can be set directly or selected from the main color in the captured frame.

[color=gray][size=4][i][b]Progress Meter[/b][/i][/size][/color]

The mod adds a second level-style meter to the Loading Menu. It tracks Skyrim's reference, critical-reference, and distant-reference loading queues.

The progress meter is a secondary feature and should still be considered experimental. Skyrim performs other background work that is not tracked yet, so the meter may finish before the Loading Menu closes.

The meter's position and width can be changed in the configuration file.

[color=gray][size=4][i][b]Configuration[/b][/i][/size][/color]

Settings are stored in:

[b]Data/SKSE/Plugins/SkyrimLoadProgress.toml[/b]

The included TOML file explains every setting.

You can change:

[list=1]
[*]Progress meter X and Y position.[/*]
[*]Progress meter width.[/*]
[*]Whether blur is enabled.[/*]
[*]Blur strength.[/*]
[*]Transition delays and fade times.[/*]
[*]The default transition used when a cell is not in memory.[/*]
[*]Fixed or dominant transition colors.[/*]
[*]Transition rules based on Cell Editor IDs.[/*]
[/list]

Cell rules are not case-sensitive. They support [b]*[/b] and [b]?[/b] wildcards.

Rules are checked from top to bottom. The first matching rule is used.

Settings are loaded when Skyrim finishes loading its game data. Restart the game after changing the file.

[color=gray][size=4][i][b]Installation[/b][/i][/size][/color]

[b]Mod Organizer 2 or Vortex[/b]

[list=1]
[*]Install the archive using your mod manager.[/*]
[*]Enable the mod.[/*]
[*]Make sure SKSE64 and Address Library are installed.[/*]
[*]Launch Skyrim through SKSE.[/*]
[/list]

There is no ESP to enable or sort.

[b]Manual installation[/b]

Copy the archive's [b]Data[/b] folder into the Skyrim installation folder.

The following files should be installed:

[list=1]
[*]Data/SKSE/Plugins/SkyrimLoadProgress.dll[/*]
[*]Data/SKSE/Plugins/SkyrimLoadProgress.toml[/*]
[*]Data/Interface/SkyrimLoadProgress/LoadingProgressMeter.swf[/*]
[*]Data/Interface/Exported/SkyrimLoadProgress/LoadingProgressMeter.swf[/*]
[/list]

Do not install only the DLL. The configuration file and meter files are also required.

[color=gray][size=4][i][b]Updating[/b][/i][/size][/color]

Replace the DLL and interface files with the versions from the new archive.

If you changed [b]SkyrimLoadProgress.toml[/b], compare it with the new default before replacing it. New versions may add more settings.

[color=gray][size=4][i][b]Compatibility[/b][/i][/size][/color]

Clean Loading Transitions does not edit cells, worldspaces, quests, records, or save games.

Community Shaders 1.8.4 is explicitly supported. When Community Shaders redirects ScaleForm to a separate UI target, Clean Loading Transitions composites into the retained scene target so the captured frame and UI remain in the correct order.

Loading-screen artwork and tip replacers should generally continue to work. The progress meter is loaded from a separate SWF instead of replacing the entire Loading Menu.

Mods that change or hook the following systems may conflict:

[list=1]
[*]LoadingMenu[/*]
[*]FaderMenu[/*]
[*]MistMenu[/*]
[*]The DirectX Present function[/*]
[*]The same world-rendering or ScaleForm-rendering functions[/*]
[/list]

ENB, ReShade, recording software, and other graphics tools may change when or how the transition is drawn. These combinations should be tested individually.

When reporting a compatibility problem, include your graphics setup and SKSE plugin list.

[color=gray][size=4][i][b]Known Limitations[/b][/i][/size][/color]

[list=1]
[*]This is still an experimental change to Skyrim's loading presentation.[/*]
[*]It does not reduce the time Skyrim needs to load a cell. It can still feel faster because the normal post-load fade no longer delays player control.[/*]
[*]Some pop-in may be visible while the captured frame fades away.[/*]
[*]The progress meter does not track every loading task yet.[/*]
[*]A heavily modified Loading Menu may stop the progress meter from loading or positioning correctly.[/*]
[*]Graphics tools may change the blur, colors, or drawing order.[/*]
[/list]

If the mod cannot identify the destination cell, it keeps the Loading Menu visible and uses the longer-load transition.

[color=gray][size=4][i][b]Troubleshooting[/b][/i][/size][/color]

The log is written to the normal SKSE log folder as:

[b]SkyrimLoadProgress.log[/b]

When reporting a problem, include:

[list=1]
[*]SkyrimLoadProgress.log[/*]
[*]Your exact Skyrim version[/*]
[*]Your SKSE version[/*]
[*]Your Address Library version[/*]
[*]Your SKSE plugin list[/*]
[*]Whether you use ENB, ReShade, or Community Shaders[/*]
[*]Whether the problem happens when the cell is already in memory, not in memory, or both[/*]
[/list]

[color=gray][size=4][i][b]Uninstallation[/b][/i][/size][/color]

Disable or remove the mod through your mod manager.

The mod does not store anything in your save files. A new game or save cleaner is not required.
